## 🎯 Concepto del Proyecto y Mapeo Académico

**FinGo** es la primera plataforma fintech en Colombia que no se limita a registrar gastos, sino que **centraliza activos y pasivos** en un solo panel y calcula la ruta matemática exacta para salir de deudas sin sobrecostos, empleando algoritmos de **Avalancha** (mayor tasa TEA primero) y **Bola de Nieve** (menor saldo primero).

El videojuego convierte la presentación de diapositivas convencional en una experiencia inmersiva: el jugador encarna al **Héroe FinGo**, quien debe correr esquivando amenazas financieras reales del entorno colombiano y recolectando salud económica. Al superar la distancia objetivo de cada nivel, la partida se detiene con elegancia para desplegar el **Hito Académico** correspondiente a uno de los entregables desarrollados durante el semestre:

```
[Nivel 1: Selva de Deudas] ──────────► Hito Académico 1: Visión, Problema & 5 Fuerzas de Porter
           │
[Nivel 2: Autopista Regulatoria] ────► Hito Académico 2: Sprint 2 Backlog (30 HUs / 137 pts)
           │
[Nivel 3: El Fuego Cruzado Lean] ────► Hito Académico 3: Validación Lean Startup & Pivote de Confianza
           │
[Nivel 4: Circuito Scrumban] ────────► Hito Académico 4: Sistema de OKRs, KPIs Accionables & Matriz 2x2
           │
[Nivel 5: Tormenta del MVP] ─────────► Hito Académico 5: Resolución de Conflictos, Soft Launch & Acuerdos
           │
[Nivel 6: El Océano Azul] ───────────► Hito Académico 6: Matriz ERIC Interactiva & Pitch Deck Gamma.app
```

## 🎮 Mecánicas de Juego y Controles

### 🕹️ Controles de Teclado (Computador)
- **Moverse entre los 3 carriles:** Teclas `←` / `→` o teclas `A` / `D`.
- **Saltar obstáculos a nivel del suelo:** Tecla `↑`, tecla `W` o `Barra Espaciadora`.
- **Deslizarse bajo láseres y barreras aéreas:** Tecla `↓` o tecla `S`.
- **Pausar / Reanudar partida:** Tecla `P` o tecla `Escape`.

### 📱 Controles Táctiles (Smartphones y Tablets)
- **Deslizar el dedo (Swipe):**
  - Deslizar izquierda/derecha ➡️ Cambio instantáneo de carril.
  - Deslizar hacia arriba ➡️ Salto con físicas de gravedad.
  - Deslizar hacia abajo ➡️ Deslizamiento ágil (Slide).
- **Botones virtuales en pantalla:** Botones táctiles circulares en los extremos inferiores para jugar cómodamente con los pulgares.

### ⚠️ Amenazas Financieras (Obstáculos a Esquivar)
1. **Muros Altos (Cambio de Carril obligatorio):** Tarjetas de crédito saturadas, silos organizacionales, monopolio bancario tradicional y enlaces maliciosos de phishing.
2. **Obstáculos Bajos (Saltar):** Billetes falsos, fugas de datos (brechas Ley 1581), preguntas sesgadas de encuestas y métricas de vanidad.
3. **Láseres Aéreos (Deslizarse):** Barreras de intereses ocultos, apps financieras falsas (gota a gota) y lanzamientos masivos no probados.

### ✨ Coleccionables Positivos
- 🪙 **Monedas FinGo (+10 pts):** Ahorro capitalizado.
- 🛡️ **Escudo Antifraude SFC:** Protección contra 1 colisión durante 8 segundos.
- ⚡ **Multiplicador de Avalancha (2x Puntos):** Duplica la eficiencia y puntuación durante 10 segundos.
- 💎 **Gema de Salud Financiera (+75 pts):** Reconocimiento de cumplimiento de KRs estratégicos.
- ❤️ **Respaldo de Emergencia (+1 Vida):** Recupera un corazón financiero.

## 📊 Modo Presentación Ejecutiva & Matriz ERIC (Gamma.app Style)

Si estás en medio de una sustentación académica o frente a inversionistas y no deseas jugar los 6 niveles completos, puedes presionar el botón **"Sustentación & ERIC"** en la barra superior o en el menú principal.

Este modo despliega un visor interactivo de diapositivas con:
1. **Portada Institucional:** Ficha técnica y credenciales de los 4 integrantes.
2. **Diagnóstico & Propuesta de Valor:** Comparativa entre el dolor del usuario y la solución FinGo.
3. **5 Fuerzas de Porter:** Evaluación de proveedores, clientes, sustitutos y rivalidad.
4. **Product Backlog Consolidado:** 30 Historias de Usuario, 137 puntos y los 3 frentes de trabajo.
5. **Validación Lean Startup:** Análisis de los 4 saltos de fe, por qué se refutó pedir tarjeta al inicio y el pivote a simulación express sin credenciales.
6. **Sistema de OKRs & KPIs:** Estrella del Norte, KRs cuantificables y filtro contra métricas de vanidad.
7. **Resolución de Conflictos:** El role-play de crisis (Comercial vs Tech vs Legal vs Gerencia) y la solución de Soft Launch en 3 fases.
8. **Matriz ERIC Completa (Océano Azul):** Cuadro de acciones de valor (*Eliminar, Reducir, Incrementar, Crear*) y conclusión del modelo de negocio.

## 🌐 Guía Paso a Paso para Desplegar en GitHub Pages

El proyecto está diseñado bajo una arquitectura **100% frontend estática**, sin Node.js en producción, sin servidores ni bases de datos. Se despliega en menos de 2 minutos:

### Paso 1: Subir el proyecto a tu repositorio de GitHub
```bash
git init
git add .
git commit -m "Entrega Final: FinGo Runner y Sustentación Ejecutiva"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/fingo-runner.git
git push -u origin main
```

### Paso 2: Activar GitHub Pages en el repositorio
1. Entra a tu repositorio en GitHub desde el navegador.
2. Haz clic en la pestaña **Settings** (Configuración) en la parte superior.
3. En el menú lateral izquierdo, haz clic en **Pages**.
4. En la sección **Build and deployment**:
   - **Source:** Selecciona `Deploy from a branch`.
   - **Branch:** Selecciona la rama `main` y la carpeta `/ (root)`.
   - Haz clic en **Save** (Guardar).
5. Espera entre 30 y 60 segundos. GitHub te mostrará el enlace público:
   ```
   https://TU-USUARIO.github.io/fingo-runner/
   ```
6. ¡Listo! Cualquier profesor, jurado o compañero podrá abrir el enlace desde su computador o teléfono móvil sin instalar absolutamente nada.

## 💻 Ejecución en Local (Sin Internet ni Servidores)

Para probar o ejecutar el proyecto en tu máquina local:
1. Haz doble clic directamente sobre el archivo `index.html`.
2. O ábrelo con cualquier navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
3. No requiere `npm install`, ni servidores locales como Live Server (aunque es compatible con ellos si deseas usarlo).
